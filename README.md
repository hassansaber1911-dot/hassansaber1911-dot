## How I Approach Product Work
My projects usually start with a real problem rather than a screen idea:

1. Understand the user and operational problem.
2. Define the business rules and desired outcome.
3. Reduce the idea to a testable MVP.
4. Design the core user flows and edge cases.
5. Build or prototype the experience.
6. Add measurement where useful.
7. Iterate based on what the product teaches us.
